> [!NOTE] Skills live in `.claude/skills/corpus-*`. An agent loads the right one on its own when the task matches.

## The six skills

- **corpus-design-system.** Build or change any interface: pick the right component or pattern, use only Corpus tokens, never create local components.
- **corpus-visual-consistency.** Make every screen look designed by one person: hierarchy, spacing rhythm, alignment and surfaces.
- **corpus-motion.** Decide whether and how anything animates: durations, easings, choreography, reduced motion.
- **corpus-content.** Write and review every word users see: labels, buttons, errors, empty states, in the product's voice.
- **corpus-personas.** Create the product's personas, their journeys and the taxonomy of words derived from them.
- **corpus-theme.** Personalise Corpus for a brand by changing only the theme knobs.

## Rules

- **Skills decide; the audit enforces.** A skill guides the agent's choices; the audit and the edit hook catch what slips through.
- **Skills read the decisions.** Before changing anything a record in Decisions covers, the agent reads it.
