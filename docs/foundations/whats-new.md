## v0.2.0

- **Release v0.2.0.** 2026-10-01 · —
- **⚠ Changelog, What's new and releases.** 2026-10-01 · pnpm changelog: CHANGELOG.md (grouped by release tag, Unreleased since the last; breaking changes first, detected from 'Breaking' in the message) and docs/foundations/whats-new.md (the latest 30 changes as cards) from git history.
- **Progress bar: soft liquid edges.** 2026-10-01 · The liquid's coverage gets a small sideways blur (two box passes, ~0.35 tube height), so the tip's meniscus and drops fade softly instead of looking cut out. The solid body is composited on top, so it and the tube's top and bottom stay crisp; the bar still ends exactly on its value.
- **Dropdown page merges Option and Multiselect; trailing meta/symbol; single choice has no tick.** 2026-10-01 · One Dropdown page covers Dropdown, Combobox, Multiselect and the Option row (anatomy, states, rules, keyboard, every demo). The separate Option and Multiselect pages are gone.
- **Nothing flies in from the top left; Multiselect page and chosen-first order; deprecation warnings.** 2026-10-01 · useFlip (Stack/Inline) never records positions while its container is hidden (inactive tab, closed panel): children measured 0,0 there glided in from the top-left corner when it appeared.
- **⚠ Tooltip: squircle corners, no arrow.** 2026-10-01 · Breaking look: the pointer arrow is gone and the tooltip uses squircle corners (radius-md); proximity and the 6px offset tie it to its trigger.
- **Decision records, exception review, AI card hugs content.** 2026-10-01 · docs/decisions: a new Decisions section (playground nav, llms.txt, index.json). How Corpus decides (records, supersede-don't-edit, three-team rule, exceptions, semver and deprecation) plus records for glass by elevation, status semantics, weather tint, buttons, motion, fields and options — each with the decision, why, rejected alternatives and when to revisit.
- **IconPlaceholder: tint and solid surfaces; showcase conversations use ChatThread.** 2026-10-01 · IconPlaceholder surface: 'tint' (default, a faint dark wash for white surfaces like notifications) or 'solid' (a white tile). ListItem — and so ContainedListItem — use solid inside grey list groups. New token icon-surface-solid (white; a faint lift in dark), mapped and documented.
- **Corpus mark adapts to dark mode.** 2026-10-01 · In dark mode the mark's grey half uses deep greys (gray-700 → 500) instead of glaring light ones, and the navy points turn pale blue (blue-200) so they stay visible. The favicon follows the OS colour scheme the same way.
- **⚠ Option component; whole-row selection with a left tick.** 2026-10-01 · New Option (+ OptionList): the one list-item anatomy for every dropdown list — reserved left tick slot, optional icon, label and description; default/highlighted/selected/disabled states. Owns listClasses/itemClasses/tickClasses (dropdown re-exports them).
- **Dropdown lists slide in from below; floating surfaces never grow from 0.** 2026-10-01 · Dropdown/Select/Combobox lists enter with corpus-list-rise (opacity + 8px rise, productive, no scale) and leave with corpus-list-sink; reduced motion fades.
- **Inputs: softer resting border.** 2026-10-01 · border-field now matches border (light 0.827; dark 0.42) instead of the high-contrast 0.648. Hover still strengthens to border-strong and focus adds the ring; increased contrast keeps the ≥3:1 field border (0.45).
- **Combobox: no blink on open.** 2026-10-01 · Pressing the field no longer counts as an outside interaction (the field is the popover's anchor, not its trigger), which closed the list and instantly reopened it.
- **Inline notifications on white; icon tiles are a faint dark wash.** 2026-10-01 · Inline notifications and callouts sit on raised (white) instead of layer-1. icon-surface in light mode is 5% black (was solid white), so IconPlaceholder tiles read super-light grey on any surface, including the white notice.
- **Shell layering: the page scrolls under the floating glass.** 2026-10-01 · ShellMain fills the window and scrolls; Header, LeftPanel and RightPanel float above it (absolute, 8px inset) on their glass tiers, and ShellMain is padded to start below the header (64px) and beside the side nav on large screens (256px, or 64px for the rail — LeftPanel tells the shell which). Scrolled content now passes beneath the frosted header, so the material is actually visible. ShellMain publishes --corpus-shell-top; the data table's sticky strip stops just below the header.
- **Colour semantics, enforced.** 2026-10-01 · registry/lib/status: one map from status meaning to colour, glyph, text and tint. StatusIndicator and notifications read from it; in-progress is info (never brand); warning glyphs use the base warning colour like every other status icon.
- **Warning is orange.** 2026-10-01 · -corpus-hue-warning 62.6 → 50 and the palette's orange row moves with it (CSS + JSON), so warning reads orange rather than amber. warning-foreground keeps the same hue (darker) instead of drifting 27° toward red, which made warning text look like an error.
- **Material foundation page.** 2026-10-01 · New foundations/material: the glass tiers (layer, blur, fill, use), the rules (utility not recipe, tier by layer, see-through frost, elevated surface, lift, no filtered ancestors, reduced transparency) and the nevers; live demo of the five tiers over a busy backdrop. Color links to it instead of carrying the glass section.
- **Notifications stack, newest on top; Header documents logo.** 2026-10-01 · Banners stack: the newest in front on the highest layer, each older one a layer lower, peeking out 10px beneath and 5% smaller (three show). Pointing at or tabbing into the stack fans it out into a list (FLIP glides between the two). Header doc covers the logo prop.
- **Glass: lower opacity, no bleaching.** 2026-10-01 · Fills 24 · 20 · 16 · 12 · 8% (side nav → notifications) and the light-mode backdrop lift down from 1.12 to 1.03 — the strong lift was bleaching the near-white page behind the glass to flat white, so the frost and what's behind it were invisible.
- **Corpus brand mark and favicon; Header logo slot.** 2026-10-01 · src/brand/corpus-mark.tsx: the Corpus mark — a thick ring, half a violet→blue arc (purple-400 → blue-500) and half soft grey, with three navy points (blue-900); turned 180°. Palette tokens only.
- **Glass: 30 points more transparent so content shows beneath.** 2026-10-01 · Fills 36 · 32 · 28 · 22 · 16% (side nav → notifications); blur and the light-mode backdrop lift unchanged.
- **Glass: see-through yet white.** 2026-10-01 · Fills drop below the original values (66 · 62 · 58 · 52 · 46%) and blur softens (10 · 14 · 18 · 24 · 30px), so content moving beneath stays faintly visible; the higher the layer, the more frosted. New --corpus-glass-lift brightens the backdrop in light mode (1.12; 1 in dark), so glass still reads white instead of greying into the page. Color docs table lists blur and fill per tier.
- **Glass: whiter floating layers.** 2026-10-01 · Each glass tier is 12 points more opaque (side nav 86% · header 82% · right panel/menus 78% · dialogs 72% · notifications 66%), so floating layers stand off the page instead of blending into it. The ordering holds: higher layers are still more translucent and more frosted.
- **Weather tint applies only to floating layers.** 2026-10-01 · New semantic token --corpus-elevated (raised + weather tint; mapped as --color-elevated). Glass fills from it, so only z-indexed surfaces — side nav, header, right panel, menus, popovers, dialogs, notifications, pinned toolbars — lean warm/cold. The page, in-flow containers, fields, lines and text are back on the neutral knobs. Documented in Color (Glass by elevation) and Theming.
- **Weather tint colours the layers, never the page background.** 2026-10-01 · -corpus-background reads the neutral knobs directly; every layer above it (layer-1..3, raised, fields, glass, lines, text) takes the weather tint, so Corpus's layering reads by temperature.
- **Weather tint: 'Dynamic' mode; neutral/cold/warm are fixed.** 2026-10-01 · The automatic mode is 'dynamic' (label Dynamic): the greys change with the weather. Neutral never tints, Cold is cold only, Warm is warm only. Stored 'weather'/'on' values fall back to dynamic.
- **⚠ No phantom scroll; right panel on the top layer; weather tint has three states.** 2026-10-01 · ShellMain is position: relative, so absolutely positioned content inside it (sr-only text, badges) scrolls and clips with the page instead of stretching the document (~400px of empty scroll).
- **⚠ Buttons: one primary per surface; secondary is a primary wash; rounder xl.** 2026-10-01 · Rule: exactly one primary per page, dialog or side panel; pair it with a secondary when an alternative is needed, never a second primary (Button doc, variants table).
- **No layout glide on page load; Button docs list xl.** 2026-10-01 · useFlip (built into Stack/Inline) only re-measures while the page boots or the tab is hidden, so children no longer glide in from pre-layout positions (the 'everything flies in from the top left' on load). Boot now ends after window load + fonts actually loaded (+250ms), capped at 3s.
