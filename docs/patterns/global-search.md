## The pattern

1. **Always one keystroke away.** ⌘K from any page; the capsule in the header for the mouse.
2. **A panel, not a page.** Results float over the page that stays visible behind the glass.
3. **Results as you type.** Grouped by section, top hit first and highlighted, so Enter just works.
4. **Esc unwinds.** First Esc clears the query; the next one dismisses.

## Don't

- **A search results page for simple lookups.** Only deep, filterable search earns a page.
- **Searching on Enter only.** Results update while typing.
- **A dark scrim.** The panel floats on glass; the page stays visible.
