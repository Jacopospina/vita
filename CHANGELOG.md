## Unreleased

### ⚠ Breaking

- **Tooltip: squircle corners, no arrow** (2026-10-01, 3c24e1f) — Breaking look: the pointer arrow is gone and the tooltip uses squircle corners (radius-md); proximity and the 6px offset tie it to its trigger.
- **Option component; whole-row selection with a left tick** (2026-10-01, 5d27620) — New Option (+ OptionList): the one list-item anatomy for every dropdown list — reserved left tick slot, optional icon, label and description; default/highlighted/selected/disabled states. Owns listClasses/itemClasses/tickClasses (dropdown re-exports them).
- **No phantom scroll; right panel on the top layer; weather tint has three states** (2026-10-01, e711de9) — ShellMain is position: relative, so absolutely positioned content inside it (sr-only text, badges) scrolls and clips with the page instead of stretching the document (~400px of empty scroll).
- **Buttons: one primary per surface; secondary is a primary wash; rounder xl** (2026-10-01, 61ee55b) — Rule: exactly one primary per page, dialog or side panel; pair it with a secondary when an alternative is needed, never a second primary (Button doc, variants table).
- **Right panel pattern: floats like the left panel; frosted bars no longer lose their backdrop** (2026-10-01, f45d876) — RightPanel (breaking):
- **Radius formula outward; rounded, roomier table rows** (2026-10-01, 0e92161) — rounded-outer-*: a wrapper derives its radius from the controls it holds (control radius + padding). The data table toolbar strip now uses it: 8px controls + 4px padding = 12px.
- **Chat bubbles never show an author avatar** (2026-10-01, d8564aa) — The side (agent left, person right) and the author line identify who wrote it; ChatTyping likewise. The icon prop is removed (BREAKING for ChatBubble/ChatTyping callers passing icon).
- **IconPlaceholder: one look (soft), flat, proportional radius, icon-surface token** (2026-09-30, c3f75f5) — BREAKING: IconPlaceholder drops the variant prop (filled removed); default size is md.
- **Rename IconTile to IconPlaceholder (sm/md/lg)** (2026-09-30, ab16efd) — BREAKING: IconTile → IconPlaceholder, icon-tile.tsx → icon-placeholder.tsx, IconTileTone → IconPlaceholderTone. Used by ListItem (sm) and every notification / toast banner (lg).
- **Spacing between different components; button icons always far right** (2026-09-30, ef457e3) — Inline defaults to a 12px gap and vertical centring (different components side by side); touch-or-space rule documented and added to the visual-consistency skill
- **Forms: one column, blended pairs, floating labels, required by default; no OS dropdowns** (2026-09-30, 8217ff9) — Rule one for forms: single column (F-pattern). FormRow only for one data point, blended: parent owns border/radius/background, flat fields inside, hairline between
